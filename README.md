# OmniStudio tools: issues and release notes

This repository is the public issue tracker for the browser extensions
built by Mikołaj Skrzypczyński for Salesforce OmniStudio developers:

- [OmniScript Data Inspector](https://mskrz.com/omniscript-data-inspector/)
- [OmniStudio Finder](https://mskrz.com/omnistudio-finder/)

Open an issue to report a bug or suggest a feature. Before you attach a
screenshot or a debug bundle, turn on Mask values and check that nothing
shows real data from your org. The guide
[Report a problem](https://mskrz.com/omniscript-data-inspector/guides/file-an-issue.html)
explains the steps for the Inspector.

For anything that should not be public, write to mskrz@proton.me.
